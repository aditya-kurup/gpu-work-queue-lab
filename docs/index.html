What the native project demonstrates

  • Priority scheduling with FIFO ordering inside a priority level.
  • Condition-variable wakeups for workers and idle detection without polling.
  • Aggregate in-flight memory accounting and oversized-job rejection.
  • CMake/CTest coverage for concurrent execution and memory invariants.
